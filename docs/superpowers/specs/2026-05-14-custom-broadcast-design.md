**Дата:** 2026-05-14
**Статус:** Утверждён

## Цель

Расширить ручную рассылку: после просмотра авто-отчёта администратор может вместо отправки авто-текста написать собственное сообщение, посмотреть превью и подтвердить рассылку.

## FSM

```python
class BroadcastState(StatesGroup):
    confirming        = State()  # существующее — авто-превью
    typing_custom     = State()  # новое — ожидание текста от админа
    confirming_custom = State()  # новое — превью кастомного текста
```

## Новые компоненты

### Кнопка «✏️ Свой текст»

Добавляется в клавиатуру авто-превью рядом с «✅ Отправить всем» и «❌ Отмена».
`callback_data = "bcast_custom_start"`

### Handlers

| Триггер | Состояние | Действие |
|---------|-----------|---------|
| callback `bcast_custom_start` | `BroadcastState.confirming` | Очищает данные состояния, отвечает «Введите текст для рассылки:», переходит в `typing_custom` |
| message (текст) | `BroadcastState.typing_custom` | Валидирует, сохраняет в `state.data["custom_text"]`, показывает превью, переходит в `confirming_custom` |
| callback `bcast_confirm_custom` | `BroadcastState.confirming_custom` | Извлекает текст из state, вызывает `send_broadcast_text`, очищает состояние |
| callback `bcast_edit_custom` | `BroadcastState.confirming_custom` | Отвечает «Введите новый текст для рассылки:», переходит в `typing_custom` |
| callback `bcast_cancel` | любое | Уже существует — очищает состояние, «Рассылка отменена.» |

### Функция `send_broadcast_text`

```python
async def send_broadcast_text(bot, text: str) -> int:
```

- Получает всех активных пользователей через `get_active_users()`
- Отправляет `text` каждому через `bot.send_message(telegram_id, text)` без `parse_mode`
- При `TelegramForbiddenError` («bot was blocked») вызывает `deactivate_user(telegram_id)`
- При других ошибках — логирует и продолжает следующему
- Возвращает количество успешно отправленных

## Валидация текста

| Условие | Поведение |
|---------|-----------|
| Пустая строка / только пробелы | «Текст не может быть пустым. Введите сообщение:» — остаёмся в `typing_custom` |
| Длина > 4096 символов | «Слишком длинный текст (максимум 4096 символов). Введите короче:» — остаёмся в `typing_custom` |
| Корректный текст | Показываем превью, переходим в `confirming_custom` |

---

## Что НЕ меняется

- Авто-рассылка по расписанию (APScheduler, понедельник 9:30)
- `send_broadcast` — функция авто-рассылки не трогается
- `last_processed_date` не обновляется при кастомной рассылке
- Фильтры `admin_filters` к кастомному тексту не применяются (текст произвольный)
- Футер с ссылкой на аналитику к кастомному тексту не добавляется

## Тесты (`tests/test_broadcast.py`)

| Тест | Что проверяет |
|------|--------------|
| `test_send_broadcast_text_sends_to_all_users` | Кастомный текст разослан всем активным пользователям |
| `test_send_broadcast_text_no_users` | Нет активных пользователей → возвращает 0 |
| `test_send_broadcast_text_continues_after_error` | Ошибка у одного пользователя → остальные получают |
| `test_send_broadcast_text_deactivates_blocked_user` | «bot was blocked» → вызывает `deactivate_user` |
| `test_send_broadcast_text_no_parse_mode` | Сообщение отправляется без parse_mode |
| `test_custom_text_empty_rejected` | Пустой ввод → не переходит к превью, просит ввести снова |
| `test_custom_text_too_long_rejected` | Текст > 4096 символов → отклоняется с сообщением |

Итого ожидается **~51 тест** (44 существующих + 7 новых).
